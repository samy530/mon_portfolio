SmartInvoice - Extraction automatique de données factures (PFE)

Conception et réalisation d'un système intelligent d'extraction automatique d'informations à partir de factures, combinant la reconnaissance optique de caractères (OCR) et les grands modèles de langage (LLM) pour surpasser les limites des approches traditionnelles.

  • Architecture modulaire : Pipeline en 5 blocs (Prétraitement image, OCR, Extraction LLM, Détection d'anomalies, Gestion des données)
  • Gestion multi-rôles : Utilisateur personnel, Employé, Responsable d'entreprise, Administrateur système (Authentification JWT)
  • Évaluation rigoureuse : Test de 15 configurations (3 OCR + 6 LLM) sur 53 factures annotées manuellement
  • Performance record : Taux d'exactitude globale de 79% et taux d'approximation de 92,08% (Meilleure config: EasyOCR + Groq Llama 3.3)
  • Détection d'anomalies : Validation automatique des incohérences sur les dates, montants, devises et numéros de facture
  • Interface complète : Dashboard personnalisé, export CSV, historique et visualisation des documents

BookEase - Plateforme de réservation de salles

Développement d'une plateforme web permettant la location et réservation de salles de réunion/événements avec gestion multi-rôles, interface intuitive et API REST.

  • 3 rôles : Client, Propriétaire, Administrateur
  • Recherche avancée : localisation, prix, capacité, équipements
  • Carte interactive Mapbox pour visualiser et géolocaliser les salles
  • Réservation en 3 étapes avec génération de code de confirmation
  • Dashboards personnalisés avec statistiques et gestion complète
  • Système d'avis et de notation après réservation
